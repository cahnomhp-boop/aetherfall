# Aetherfall 2.5D

Game RPG 2.5D berbasis **Three.js**  
Dibuat full 1 file (index.html) dan siap jalan di GitHub Pages.

## 🎮 Kontrol
- W A S D : Gerak
- Fire / Ice / Light : Skill
- Potion : Heal
- ESC : Pause

## 🚀 Cara Jalanin (GitHub Pages)
1. Upload repo ini ke GitHub
2. Masuk **Settings → Pages**
3. Source: `Deploy from branch`
4. Branch: `main` / `(root)`
5. Save
6. Buka link GitHub Pages 🎉

## 🧠 Fitur
- 2.5D Camera Follow
- Enemy AI (chase)
- Skill System + Cooldown
- Leveling & EXP
- Merchant & Shop
- Pause & Story Intro

## ⚙ Tech
- HTML + CSS
- JavaScript
- Three.js (CDN)
